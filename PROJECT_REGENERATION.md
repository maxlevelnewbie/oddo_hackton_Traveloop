## 🆘 Troubleshooting

### If npm install fails:
```bash
npm cache clean --force
rm package-lock.json
npm install
```

### If database connection fails:
```bash
# Check .env.local DATABASE_URL
# Ensure PostgreSQL is running
npm run db:push
```

### If TypeScript errors:
```bash
npm run type-check
npm run prisma:generate
```
